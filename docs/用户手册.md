# 用户手册（EntelechySystem）

> 文档定位：面向“使用者/研究者”，目标是尽快跑通一个实验、理解配置怎么改、以及如何找到输出结果。

## 1. 你可以用这个仓库做什么

- 以“实验脚本 + 配置”的方式运行 ES 的模拟器。
- 在 `EntelechySystem_python/Libraries/` 中选择不同的系统、世界环境、模型、参数、设置等组合进行实验。

## 2. 快速开始（Windows）

### 2.1 安装 Python

- 需要 Python `>= 3.12`。

### 2.2 安装依赖

在仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
```

### 2.3 运行一个示例实验

仓库提供了一个示例入口：

```powershell
python EntelechySystem_python\Experiments\EXP_test_010.py
```

该脚本会调用模拟器入口 `EntelechySystem_python/simulator.py` 中的 `simulator(config)`。

## 3. 配置怎么改

### 3.1 配置从哪里来

运行时会读取 `config` 字典中的 `folderpath_config` 指向的配置目录。

示例实验脚本（`EXP_test_010.py`）里默认是：
- `folderpath_config = EntelechySystem_python/Libraries/ConfigsLibrary/config_test`

另外仓库还有一份常用工作区配置目录：
- `workstage/config/`

### 3.2 常用配置项（入门）

你最常改的一般是这些字段：

- `folderpath_world_environment`：世界环境库路径（选择不同环境）。
- `folderpath_models`：模型库路径（Numpy / PyTorch / JAX 等方案）。
- `folderpath_system`：系统库路径（系统组织与调度方式）。
- `list_idsExperiment_to_run`：要运行的实验编号列表。
- `program_实验组模拟程序`：是否运行实验组模拟。

### 3.3 Excel 配置与 Python 配置

配置通常支持两种来源：

- `config.py`（可读可版本化）
- `config.xlsx`（更易编辑、面向表格）

以及一个缓存：
- `config.pkl`（快速加载）

配置目录内的 `config_program.py` 通常负责做转换与导出 `config.pkl`。

> 提示：如果你改了 `config.xlsx`，但运行仍读到了旧配置，可能需要先运行/触发一次 `config_program.py` 来更新 `config.pkl`。

## 4. 输出结果在哪里

输出目录由配置项共同决定，常见相关字段包括：
- `folderpath_root_experiments`（如 `SimulationsData`）
- `foldername_outputData`（如 `EntelechyData`）
- 实验文件夹命名策略（前缀、是否带日期时间等）

运行结束后，建议优先在输出目录中查找：
- `outputlog.txt` 或类似日志
- `config/gb.pkl`（一次运行的全局配置快照）

## 5. 常见问题

### 5.1 在 VS Code 里点“运行”没反应/卡住

某些配置的注释指出：当 `is_prerun_config_program=False` 时，用交互控制台运行可能不会继续推进。

建议：
- 用终端直接运行命令 `python ...\EXP_test_010.py`。

### 5.2 依赖安装失败

- 确认 Python 版本满足 `>=3.12`。
- 先升级 pip：`python -m pip install -U pip`。
- 如遇到科学计算/深度学习包下载慢，建议切换镜像或使用团队既定安装方式。
