## 日志规范

每条日志建议包含：

- **日期**：YYYY-MM-DD
- **类型**：特性 / 修复 / 重构 / 文档 / 依赖 / 配置 / 实验
- **范围**：模块/目录（例如 `EntelechySystem_python/engine`）
- **内容**：做了什么 & 为什么
- **影响**：是否破坏兼容、是否影响实验结果/输出结构
- **验证**：运行了哪些脚本/做了哪些检查
